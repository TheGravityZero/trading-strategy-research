# Crypto four-week reversal

> Historical result: сохранённые конфигурации рассчитаны на старой
> десятиактивной вселенной. Для HYPE, BTC, SOL и ETH нужен новый прогон.

## Идея

После пробоя экстремума четырёх завершённых недель стратегия ставит
контртрендовый лимитный ордер на 4% дальше уровня. Ордер живёт 60 минут.
Направление импульса должно совпадать с предшествующим четырёхчасовым трендом.
Результат измеряется через 15, 30 и 60 минут.

## Запуск

```bash
PYTHONPATH=src python strategies/run_crypto_four_week_reversal.py
```

| Research | 60m | -320.86 bps | -334.86 bps |
| Validation | 15m | -515.60 bps | -529.60 bps |
| Validation | 60m | -460.89 bps | -474.89 bps |

Вывод: безусловный контртрендовый вход отклонён. После исполнения цена обычно
продолжает движение пробоя. Условие 4% можно использовать как setup для
последующего подтверждения разворота.

Конфигурации:

- [`reclaim/`](reclaim/) — вход после возврата за недельный уровень.
- [`offset-4pct/`](offset-4pct/) — лимит на 4% дальше уровня.
